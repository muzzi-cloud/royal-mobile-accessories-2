ROYAL MOBILE ACCESSORIES — 3D DESIGN CONCEPT
=============================================
Open index.html in a modern browser. Internet is recommended for stock images and web fonts.

INCLUDED PAGES
- index.html: premium homepage with CSS 3D phone hero and floating elements
- shop.html: 25 products, search, category/price filters, sorting
- cart.html: quantity controls, remove items and subtotal
- checkout.html: demo checkout flow
- about.html: 3D-inspired brand story
- contact.html: sample contact form
- products.js: product catalogue with sample PKR prices
- app.js: product rendering, cart and demo interactions
- style.css: responsive layout, CSS 3D scenes and animations

IMPORTANT
This is a front-end concept/demo, not a production store. Prices are illustrative. Images are stock
references and may not depict exact products. Cart data stays in the visitor's browser. Checkout,
contact and any newsletter do not send data or process real orders/payments. No database, admin
panel, shipping provider, authentication or payment gateway is connected.

Before using for a real business, replace the product details, prices, images, logo/trademark review,
contact information, policies and add a secure backend, real order flow, payment integration and
privacy/security measures. Do not represent demo orders or sample stock as real.
